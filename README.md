# Workout Helper

## Project Overview

Workout Helper is a local-first web application designed to guide users through their exercise routines. It provides structured workouts, manages rest timers, tracks workout history, and calculates workout streaks. The application operates entirely offline, storing all user data directly in the browser's local storage. Its minimalist and modern design focuses on providing a clean, distraction-free user experience.

## Features

*   **Guided Workouts:** Step-by-step guidance through predefined workout routines.
*   **Rest Timers:** Automatic management of rest periods between sets and exercises.
*   **Workout History:** Records and displays all completed workouts with key statistics.
*   **Workout Streak:** Calculates and displays the user's consecutive workout streak.
*   **Offline Functionality:** Works completely without an internet connection.
*   **Progressive Web App (PWA):** Installable on devices for quick access and an app-like experience.
*   **Minimalist UI:** Clean, modern, and dark-themed user interface.

## Technologies Used

*   **Frontend:** HTML5, CSS3
*   **Interactivity:** Alpine.js (a lightweight JavaScript framework)
*   **Data Storage:** Browser's `localStorage` for user data, JSON for workout definitions.
*   **Styling:** Custom CSS with Google Fonts (Inter).

## How to Run

1.  **Clone or Download:** Get the project files to your local machine.
2.  **Open `index.html`:** Navigate to the project directory and open the `index.html` file in your preferred web browser. No special build steps or server setup are required.

### PWA Installation

For an enhanced app-like experience, you can install the Workout Helper as a Progressive Web App on your device:

1.  **Open in Browser:** Open the `index.html` file in a compatible web browser (e.g., Chrome, Edge, Safari).
2.  **Install Option:** Look for an "Install app" or "Add to Home Screen" option in your browser's menu (often found in the three-dot menu on Android/Chrome or the share sheet on iOS/Safari).
3.  **Launch:** Once installed, the app will appear on your home screen or app launcher and can be launched like a native application.

## Future Plans

The current version provides core functionality, but there are many possibilities for future enhancements:

*   **Achievements System:** Implement a system to reward users for reaching workout milestones.
*   **Customizable Workouts:** Allow users to create, edit, and save their own workout routines.
*   **More Detailed Statistics:** Expand the statistics tracking to include exercise-specific metrics, total time spent, and more advanced progress visualization.
*   **Sound and Vibration Feedback:** Add audio cues and haptic feedback for timer completion and set transitions.
*   **Data Export/Import:** Provide options to export workout history and import custom workouts.
*   **Improved UI/UX:** Further refine the user interface based on user feedback and best practices.
*   **Push Notifications:** For reminding users about upcoming workouts or streak maintenance.
